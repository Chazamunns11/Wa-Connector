# PingWren brand kit

Logo: **Bubble Wren**, a wren inside a speech bubble. The wordmark is lowercase `pingwren`: "ping" in weight 800 and "wren" in weight 500, set in Bricolage Grotesque. The SVGs have their text converted to shapes, so no font needs to be installed.

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#1B1F2A` | Bubble, "ping", dark backgrounds |
| Wren | `#7A4E2D` | "wren" on light backgrounds |
| Tan | `#D9A47A` | "wren" on dark backgrounds |
| Cream | `#F6F1EA` | Light backgrounds, the wren itself |
| Coral | `#FF5A36` | The beak (the "ping") and the accent / CTA colour |

Don't use WhatsApp green (#25D366) or WhatsApp's logo anywhere in the brand.

## Type

- Display / headings: Bricolage Grotesque, weights 500 and 800, from Google Fonts.
- Body text: choose a plain sans that suits the site. Keep the logo in Bricolage.

## Files

| File | Use |
| --- | --- |
| `pingwren-logo.svg` | Main horizontal logo, for light backgrounds |
| `pingwren-logo-reverse.svg` | Horizontal logo for dark backgrounds |
| `pingwren-logo-stacked.svg` / `-stacked-reverse.svg` | Square-ish layouts |
| `pingwren-logo-black.svg` / `-white.svg` | One-colour versions (wren is cut out) |
| `pingwren-mark.svg` / `-reverse.svg` / `-black.svg` / `-white.svg` | Icon only |
| `pingwren-app-icon.svg`, `-512.png`, `-1024.png` | App icon / GHL Marketplace tile (coral square) |
| `favicon.svg`, `favicon.ico`, `favicon-*.png` | Browser tab; 180px is the Apple touch icon |
| `*@3x.png`, `*-1024.png` | PNG versions with transparent backgrounds |

Leave clear space around the logo of at least the height of the wren's head. Don't recolour, stretch or outline the mark.
