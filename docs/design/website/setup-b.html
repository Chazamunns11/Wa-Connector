Set up <Brand> in GoHighLevel

About ten minutes. Pick the guide that matches your account.

Agency owner

  1. Install

    Open the install link from your welcome email, or find the app in the Marketplace, and install it on your agency account.

  2. Open the WhatsApp page

    In a sub-account, choose WhatsApp in the left menu.

  3. Set the Telephony Provider

    Settings, Phone System, Advanced Settings, Telephony Provider. Choose the connector and Save. Without this, a connected number will not send.

  4. Scan the QR code

    On your phone: WhatsApp, Settings, Linked Devices, Link a Device. Scan the code.

  5. Confirm it is connected

    The row shows Connected with the number.

  6. Send a test

    Run a workflow with a Send SMS step to your own phone.

  7. Reply

    Answer on WhatsApp and see it in Conversations.

Troubleshooting

Connected but not sending

Check the Telephony Provider is set to the connector (Settings, Phone System, Advanced Settings).

QR code expired

Refresh the page for a new code and scan within a minute.

Messages waiting

The phone is disconnected. Open WhatsApp on it and check it is online.

My agency blocks installs

Ask your agency to install the app for your sub-account, or to allow app installs for it.

Number at the linked-device limit

Remove a device in WhatsApp, Linked Devices, then link again.
