# `<Brand>` Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The customer-facing `<Brand>` site: a sales page, pricing with a live calculator, the GoHighLevel setup guide, docs and legal placeholders, all real now; plus signup, checkout, dashboard and billing screens that work on sample data behind one `AccountDataSource` interface, visibly marked "Preview", until the accounts-and-billing stage swaps in real accounts and Stripe.

**Architecture:** Marketing pages live in the `src/app/(site)/` route group (shared header/footer layout, server components, no client JS beyond two small islands: the pricing calculator and the setup-guide tabs). Signed-in screens live in `src/app/(app)/` and read everything through `getAccountDataSource()`, which returns `PreviewAccountDataSource` today. Every brand-specific value (name, tagline, colours, logo, support contacts, price, currency) comes from `brandConfig()` so applying the chosen brand is one env change. All testable logic (pricing, FAQ, setup steps, sample data, dashboard derivations) lives in plain `.ts` modules; `.tsx` files are thin renderers, because the `node --test` harness strips types but does not compile JSX.

**Tech Stack:** Next.js **16.2.10** (App Router, `proxy.ts` convention, async `searchParams`), React 19.2.4, Tailwind 4 with the token set in `src/app/globals.css`, TypeScript 5, `node --test` via `scripts/test/alias-hook.mjs`. Design: superdesign CLI for drafts; frontend-design + ui-ux-pro-max for the build; sales-page + human-writing for copy. Verification: Playwright 1.56.1 (global at `/opt/node-tools/node_modules`, Chromium at `/opt/pw-browsers/chromium`).

**Spec:** `docs/superpowers/specs/2026-10-16-website-design.md` (authority for the website), building on `docs/superpowers/specs/2026-10-12-brand-whatsapp-saas-design.md` (pricing, trial, login, dashboard, in-GHL page; "Revision: standalone").
